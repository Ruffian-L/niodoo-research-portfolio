# Silos

Two drawers. Do not merge them.

This is working research. Results from different days and different protocols are allowed to disagree. If you mix these folders into one table you will start investigating the git instead of using it.

| Drawer | Path | Use |
|--------|------|-----|
| **Live** | [`live/`](live/) | Survived its own check. Take it into the next run. |
| **Trail** | [`trail/`](trail/) | Already walked. Protocol that did not hold, mechanism that is dead in practice, or a margin that was the scorer. Read it so you do not pay for it twice. |

Do not call these wins and losses. They are receipts, sorted so the next person can work.
