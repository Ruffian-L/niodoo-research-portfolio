# Contamination this git refuses

**Date of this note:** 2026-08-20  
**Owner:** Jason Van Pham

This folder is the stop layer for papers that look like research product and
are not. The Path B extra-tag manuscript remains on disk, gitignored.

## The tags paper

Jason's control channel is real. The model writes a tag mid-decode; a sliding
buffer catches it even when the tag splits across tokens; the runtime
dispatches inside the same generation pass. That mechanism is in source, in
dated logs, and in `ULTIMA_NIODOO.md` §3.3.

The **four physics tags** in the April contract are `SPIKE`, `EXPLORE`,
`FOCUS`, and `RESET`. `REMEMBER` and `LOCK` are the agency surface (write to
the durable store; commit-and-stop). Those are Jason's tags.

What happened next is the contamination:

1. A plan writer put **extra tags** into `## Acceptance criteria` on a goal
   about this channel. Jason did not ask for those tags.
2. An implementer then wrote a manuscript about the expanded set —
   `Emitted_Control_Tags_Path_B.md` — as if the unasked vocabulary were the
   commissioned paper.

That manuscript is not in this git. The renderer next to it
(`render_emitted_control_tags.py`) and the PDF render are not in this git.
The control channel itself is still described, narrowly, in the ultima.

A separate publication hold already existed for a related error: the system
prompt taught the request vocabulary, so printed tags are evidence of
symbolic policy use, not of emergent metacognition. Do not revive that claim
from the excluded file.

## What this is not

This is not a claim that control tags are fake. It is not a claim that Echo,
Lumina, Shep, or the 2025-11-19 dream-cycle line did not happen. It is a
claim about **which files are papers Jason is putting on this git**.
